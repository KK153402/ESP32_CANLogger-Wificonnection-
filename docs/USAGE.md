# CANログ取得治具 操作手順書

現場でCANログを取得し、解析側へ送るまでの手順。

---

## 1. 治具の構成

```
┌─────────────────────────────────┐
│  [LED]        [開始]  [停止]     │
│                                 │
│  [CH1]  [CH2]        [USB-C]    │
│  500k   250k          [SD]      │
└─────────────────────────────────┘
```

| 部位 | 用途 |
|---|---|
| CH1コネクタ | 測定対象の**500kbps**バスへ接続 |
| CH2コネクタ | 測定対象の**250kbps**バスへ接続 |
| 開始ボタン | 記録開始 |
| 停止ボタン | 記録停止 |
| LED | 状態表示（§3） |
| USB-C | 電源。**モバイルバッテリー**から給電 |
| microSD | ログの保存先 |

> **Wi-Fiアップロード機能**が使える構成もあります。§10を参照してください。
> 設定していない場合は、従来どおりSDカードを持ち帰る運用のままで問題ありません。

> **CH1とCH2のコネクタは同じ形状です。** ケーブルのタグと基板の刻印を必ず確認してください。
> 挿し間違えてもエラーは出ず、**そのチャネルだけ0件で終わります**（§6で確認できます）。

---

## 2. 準備

### 事前に用意するもの

- microSDカード（FAT32でフォーマット済み、8GB程度で十分）
- USBモバイルバッテリー
- CAN接続ケーブル（CH1用・CH2用）

### 接続

1. microSDカードを挿す
2. USBモバイルバッテリーを繋ぐ
3. LEDが**消灯**していることを確認する（＝準備完了）

> **LEDが高速点滅する場合**は異常です。§5を確認してください。

---

## 3. LEDの見方

| LED | 状態 | 意味 |
|---|---|---|
| **消灯** | 待機 | 準備完了。開始ボタンを押せる |
| **ゆっくり点滅**（1秒に2〜3回） | 記録中 | **SDカードを抜かないこと** |
| **短く2回ずつ点滅**（1秒周期） | 送信中 | ログをアップロード中。**SDカードを抜かないこと** |
| **点灯したまま** | 停止完了 | **SDカードを抜いてよい** |
| **高速点滅**（1秒に6回） | 異常 | §5を参照 |

**覚えることは1つだけです。**

> **点滅している間はSDカードを抜かない。点灯に変わってから抜く。**

送信中の点滅も同じルールで扱ってください。送信が終われば点灯に戻ります。

---

## 4. 記録の手順

### 手順

| # | 操作 | 確認すること |
|---|---|---|
| 1 | 電源を入れる | LEDが**消灯** |
| 2 | CH1・CH2のケーブルを接続する | タグと刻印が合っているか |
| 3 | **開始ボタン**を押す | LEDが**点滅を始める** |
| 4 | 事象を再現させる | — |
| 5 | **停止ボタン**を押す | LEDが**点灯に変わるまで待つ** |
| 6 | SDカードを抜く | LEDが点灯していること |

### 注意

- **停止ボタンを押してから、LEDが点灯に変わるまで数秒かかります。** 焦らず待ってください
- 点滅中にSDカードを抜くと**ファイルが壊れます**
- 記録中に電源が切れた場合も、そこまでのデータは残っていることが多いです。SDカードを抜いて解析側へ送ってください
- 記録は自動では止まりません。**必ず停止ボタンを押してください**
- 停止後にLEDが**短く2回ずつ点滅**し始めたら、アップロード中です。点灯に変わるまで待ってください

### 記録時間の目安

| 記録時間 | ファイルサイズの目安 |
|---|---|
| 1分 | 約2 MB |
| 10分 | 約20 MB |
| 1時間 | 約120 MB |

8GBのSDカードなら数十時間分記録できます。**長めに録っても問題ありません。**

---

## 5. 異常時の対応

LEDが**高速点滅**したときの対処です。

| 状況 | 確認すること |
|---|---|
| 電源投入直後から高速点滅 | SDカードが挿さっているか。別のカードで試す |
| 開始ボタンを押したら高速点滅 | SDカードの空き容量。書き込み禁止になっていないか |
| 記録中に高速点滅に変わった | SDカードの接触不良か容量不足。**そこまでのログは保存されています** |

### 復帰のしかた

1. **開始ボタンを押す**と再試行します
2. 直らない場合は電源を入れ直す
3. それでも直らない場合は、SDカードを抜いて管理者へ連絡してください

**高速点滅になっても、それまでに記録したログとエラー内容はSDカードに残っています。**
カードを抜いて解析側へ送れば、原因が分かります。

---

## 6. 記録後の確認（重要）

SDカードには2つのファイルができます。

| ファイル | 内容 |
|---|---|
| `LOG0001.BIN` | CANログ本体 |
| `LOG0001.TXT` | **記録結果のレポート** |

**`LOG0001.TXT` をメモ帳で開いて、以下を確認してください。**

```
exit            : normal (stop button)      ← ここが normal であること

-- CH1 (internal TWAI) --
frames logged   : 2747                      ← 0 でないこと
ring dropped    : 0   (frames)              ← 0 であること
ctrl missed     : 0   (frames)              ← 0 であること

-- CH2 (MCP2515) --
frames logged   : 54263                     ← 0 でないこと
ring dropped    : 0   (frames)              ← 0 であること
ctrl ovf events : 0   (events, not frames)  ← 0 であること

result          : OK                        ← これが出れば全部問題なし
```

### 判定

| 表示 | 意味 | 対応 |
|---|---|---|
| `result : OK` | **問題なし** | そのまま送付 |
| `CH1 received nothing` | CH1が0件 | **ケーブルの挿し間違い**の可能性。接続を確認して録り直す |
| `CH2 received nothing` | CH2が0件 | 同上 |
| `frame loss detected` | 取りこぼしあり | 送付してよいが、解析側へ一報 |
| `exit : ABNORMAL` | 異常終了 | `fault` 行の内容とあわせて管理者へ連絡 |

> **片方だけ0件の場合は、ほぼ挿し間違いです。** CH1とCH2のケーブルを入れ替えて録り直してください。

---

## 7. 解析側への送付

以下をセットで送ってください。

- `LOG0001.BIN`（ログ本体）
- `LOG0001.TXT`（レポート）
- **記録した日時**（治具のRTCが未設定の場合に必要）
- 現地の状況（何をしたときに、どんな事象が起きたか）

ファイルは記録するたびに `LOG0002`, `LOG0003`... と番号が増えます。
**複数回記録した場合は、どれがどの事象か分かるようにメモを添えてください。**

---

## 8. やってはいけないこと

| 禁止事項 | 理由 |
|---|---|
| **点滅中にSDカードを抜く** | ファイルが壊れる |
| **測定中にPCを接続する** | グランドループができて治具や測定対象を壊す恐れがある |
| **高電圧のバスに接続する** | この治具は**制御系CAN専用**です |
| コネクタを無理に挿す | CH1とCH2は形状が同じです。タグを確認してください |

---

## 9. 困ったときは

| 症状 | 対応 |
|---|---|
| LEDが全く点かない | モバイルバッテリーの残量。USBケーブルを替えてみる |
| 開始ボタンを押しても点滅しない | LEDが高速点滅していないか確認（§5） |
| SDカードが認識されない | FAT32でフォーマットし直す |
| ファイルが作られない | SDカードの空き容量と書き込み禁止スイッチ |

上記で解決しない場合は、**SDカードを抜いて管理者へ連絡**してください。

---

## 10. Wi-Fiアップロード（設定してある場合のみ）

SDカードを持ち帰らずに、ログをサーバーへ自動送信する機能です。
**設定していない治具では何も起きません。** 従来どおりの操作で使えます。

### 10.1 何が起きるか

```
記録を停止する
  ↓
LEDが「短く2回ずつ点滅」に変わる   ← 送信中
  ↓
サーバーにログが届く
  ↓
LEDが点灯に戻る                     ← SDカードを抜いてよい
```

**送信中もSDカードからログは消えません。** 送信が失敗しても、カードを持ち帰れば回収できます。

### 10.2 記録中は送信されません

**記録中（ゆっくり点滅）はアップロードが完全に停止します。**
送信中に開始ボタンを押した場合も、送信が中断されて記録が優先されます。

中断された送信は、記録が終わってから自動的に続きから再開されます。

### 10.3 事前設定

SDカードのルートに `CONFIG.TXT` を置きます。

```
WIFI_SSID = 接続先のSSID
WIFI_PASS = パスワード
UP_HOST   = 送信先のIPアドレス
UP_PORT   = 8080
DEVICE_ID = JIG001
```

| 項目 | 内容 |
|---|---|
| `DEVICE_ID` | 治具の識別名。**治具ごとに変えてください**。送信先のフォルダ名になります |
| `UP_ENABLE` | `0` にするとアップロードを止められます |

> **ファイルが無くても起動します。** その場合はアップロードしないだけで、記録は通常どおり動きます。

### 10.4 動いているか確認したいとき

治具のUSB-CをPCに繋ぎ、シリアルモニタ（115200bps）で `UPSTAT` と打ちます。

```
> UPSTAT
upload  : phase=idle  boot#=4  ok=6  fail=0  sent=1715725 byte
          last: LOG0006 uploaded (2 parts)
wifi    : your-ssid  ip=192.168.10.106  rssi=-43 dBm
policy  : A (everything auto)
dest    : http://192.168.10.104:8080/canlog/JIG001/  chunk=1024 KB
```

| 表示 | 意味 |
|---|---|
| `phase=idle` | 送るものが無い（=全部送信済み） |
| `phase=sending` | 送信中 |
| `phase=blocked` | 記録中なので停止している |
| `phase=retry` | 失敗して再試行待ち |
| `fail=0` | 通信エラーなし。**0でなければ電波かサーバーを疑う** |

> **測定中にPCを接続しないでください。** グランドループができて治具や測定対象を壊す恐れがあります（§8）。
> `UPSTAT` の確認は、測定対象から切り離した状態で行ってください。

### 10.5 うまくいかないとき

| 症状 | 確認すること |
|---|---|
| LEDが点滅に変わらない | `CONFIG.TXT` の `WIFI_SSID` / `UP_HOST` が空でないか |
| `connect failed` が出る | サーバーが起動しているか。PCのファイアウォールで通信が止められていないか |
| `wifi connect timeout` | SSIDとパスワード。治具が電波の届く場所にあるか |
| 急に繋がらなくなった | サーバーPCのIPアドレスが変わっていないか |

**どの場合でも、SDカードにログは残っています。** カードを持ち帰れば回収できます。

### 10.6 送信されたファイル

サーバー側にはこのように置かれます。

```
canlog/JIG001/
    20260901_150227_LOG0006.txt        レポート
    20260901_150227_LOG0006_001.bin    ログ本体（分割）
    20260901_150227_LOG0006_002.bin
```

**ログ本体は1MBごとに分割されています。** 解析側で連結してから使います。

```bash
python tools/merge_parts.py canlog/JIG001
```

```

□ CH2ケーブル … 250kbps側へ接続

□ 事象を再現させた

□ LEDが点灯に変わるのを待った（送信中の点滅が終わるまで待つ）
□ SDカードを抜いた
□ LOG____.TXT を開いて result : OK を確認した
□ 記録日時をメモした（         年   月   日   時   分）
□ 事象の内容をメモした
```
